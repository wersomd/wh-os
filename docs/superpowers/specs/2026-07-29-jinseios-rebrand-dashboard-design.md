# JinseiOS — ребрендинг + обновление дашборда

Дата: 2026-07-29
Статус: одобрено к реализации

## Обзор

Переименование продукта «Wediff» → **JinseiOS** (人生 «jinsei» = жизнь + OS = «операционная
система жизни»), смена визуального направления на **спокойный минимализм** (dark-first,
графит/sumi-ink + приглушённый индиго-акцент) и добавление двух новых виджетов на дашборд:
**«Сегодня» (фокус-блок)** и **Финансовый пульс**.

Продукт — личная «ОС для жизни» на одного пользователя, русский интерфейс, 13 модулей.

## Цели

1. Единая бренд-идентика JinseiOS с японским логознаком 人生.
2. Приглушённая, «премиальная» палитра — уйти от яркого электрик-фиолета.
3. Дашборд, который с первого взгляда отвечает «что сегодня» и «как с деньгами».

## Не-цели (YAGNI)

- Виджеты streak-привычек и колец целей — не сейчас (легко добавить позже той же сеткой).
- Переписывание layout остальных 12 модулей — они подхватывают новые токены автоматически.
- Смена данных/схемы БД — используем существующие поля.

## 1. Бренд

- **Имя:** JinseiOS. Вордмарк `JinseiOS` (латиница); в узких местах — строчное `jinsei`.
- **Логознак:** кандзи **人生** в скруглённом квадрате с приглушённым индиго (фон/градиент).
  Фавикон — тот же знак. Пара «латиница + 人生» читаема и передаёт смысл «ОС для жизни».
- `siteConfig.name` → `"JinseiOS"`; `siteConfig.description` → «Личная операционная система жизни».
- Заменить упоминания «Wediff»/«wediff» (7 мест): `src/app/page.tsx`,
  `src/app/landing-client.tsx`, `src/config/site.ts`, `src/features/auth/login-form.tsx`,
  `src/features/jarvis/system-prompt.ts`, и `<title>`/метаданные.
- Реализация логознака: SVG-компонент `BrandMark` (кандзи 人生, цвета из токенов, не хардкод).

## 2. Палитра и токены (`src/app/globals.css`)

Dark-first остаётся. Значения — стартовые, финальная докрутка визуально.

- **Акцент** `--primary`:
  - dark: `oklch(0.646 0.246 292.717)` → `oklch(0.60 0.13 265)` (приглушённый индиго).
  - light: `oklch(0.606 0.25 292.717)` → `oklch(0.55 0.13 265)`.
  - `--ring` — в тон `--primary` (обе темы).
- **Нейтрали/фон:** увести hue из фиолетового (~285) в нейтрально-графитовый (~250–260),
  chroma держать низким (sumi-ink). `--card` отделять от `--background` тонкой границей,
  а не яркой заливкой.
- **Воздух:** крупнее отступы и `gap` на дашборде, тоньше бордеры, скругления оставить/чуть
  мягче.
- **Цифры:** `tabular-nums` для всех числовых значений (статы, финансы).
- `--success`/`--destructive` слегка приглушить, чтобы не спорили с индиго.

Все значения — только в `globals.css`; компоненты используют переменные, без хардкода цвета.

## 3. Дашборд — раскладка (`src/app/(app)/dashboard/page.tsx`)

Новый порядок сверху вниз:

1. **Хедер** — приветствие + дата (облегчить визуально; существует).
2. **🆕 «Сегодня» — фокус-блок** (hero).
3. **6 стат-карточек** — рестайл под новые токены (`StatCard`).
4. **🆕 Финансовый пульс**.

   трогаем.

## 4. Новые виджеты

### 4.1 «Сегодня» — `TodayFocus`

Крупная карточка сверху. Собирает главные дела дня:
- задачи с `Task.dueDate` = сегодня и `completedAt = null`;
- привычки без отметки за сегодня (нет `HabitEntry` с `date = сегодня` для активной `Habit`);
- (опц.) долги/подписки с датой платежа = сегодня.

Порядок: события со временем → задачи → привычки. Пусто → мягкое состояние
«На сегодня всё чисто». Клик по пункту ведёт в соответствующий модуль.

- Компонент: `src/features/dashboard/components/today-focus.tsx`.
- Данные: `src/features/dashboard/queries.ts` → `getTodayFocus()` (Server Component read).
- Зависимости: Prisma `Task`, `Habit`, `HabitEntry` (+ опц. `Debt`, `Subscription`).

### 4.2 Финансовый пульс — `FinancePulse`

Карточка «состояние денег одним взглядом»:
- **Трата за месяц vs бюджет:** сумма expense-`Transaction` за текущий месяц против суммы
  месячных `Budget.amount` → прогресс-бар с процентом. **Переиспользовать** существующую
  бюджет/трата-агрегацию из `src/features/finances/queries.ts` (суммирование по валютам —
  MVP на одного пользователя, как уже реализовано там).
- **Спарклайн:** траты по дням текущего месяца.
- **Чистые активы:** Σ текущих балансов счетов − открытые `Debt` (`status = OPEN`).
  Текущий баланс счёта = `startBalance + income − expense` — **переиспользовать**
  `getAccountsWithBalance()` из `src/features/finances/queries.ts` (у `Account` нет живого
  поля баланса, оно вычисляется). Валюты суммируются, как в существующем MVP-подходе.

- Компонент: `src/features/dashboard/components/finance-pulse.tsx`.
- Переиспользуемые примитивы: `SparkLine`, `ProgressBar` в
  `src/components/shared/` (изолированы, тестируемы отдельно).
- Данные: `getFinancePulse()` в `src/features/dashboard/queries.ts` — тонкая обёртка над
  существующими финансовыми хелперами + спарклайн-агрегат.
- Деньги: `Decimal(14,2)`, без float; формат по `siteConfig.defaultCurrency`.

## 5. Компоненты и границы

- Новые виджеты — самостоятельные единицы с одной ответственностью и явными интерфейсами:
  `TodayFocus(props)`, `FinancePulse(props)`; данные приходят из query, рендер — чистый.
- `SparkLine` / `ProgressBar` — маленькие переиспользуемые примитивы (вход: числа → SVG/бар).
- `BrandMark` — SVG-логознак 人生, цвет из токенов.
- Токены — единый источник цвета/воздуха; каскадом влияют на всё приложение.

## 6. Тестирование

- `queries.ts` — юнит-тесты агрегатов «Сегодня» и «Финансовый пульс» на сид-данных
  (границы дня/месяца, пустые состояния, деньги как Decimal).
- `SparkLine`/`ProgressBar` — рендер по крайним входам (пусто, один пункт, максимум).
- Визуальная проверка дашборда в dark-теме после смены токенов.
